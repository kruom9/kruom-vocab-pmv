ประกาศความเป็นส่วนตัว

ศัพท์สนุก Word Quest · โรงเรียนปิยมิตรวิทยา ฝ่ายมัธยม

ผู้ควบคุมข้อมูล

โรงเรียนปิยมิตรวิทยา ฝ่ายมัธยม อ.เชียงคำ จ.พะเยา (ผู้ดูแลระบบ: ครูออม) ติดต่อผ่านครูประจำวิชา/ครูที่ปรึกษา

ข้อมูลที่เก็บ (เท่าที่จำเป็น)
  • ชื่อเล่นที่ใช้แสดงในเกม, ห้องเรียน (จากรหัสห้อง), เลขที่ (ไม่บังคับ)
  • ชื่อผู้ใช้ และรหัสผ่าน (เก็บแบบเข้ารหัสทางเดียว bcrypt — ไม่มีใครเห็นรหัสผ่านจริง)
  • ผลการเล่น: คำที่ตอบถูก/ผิด ด่าน ระดับ XP วันที่เล่น
ไม่เก็บ
  • เลขประจำตัวประชาชน เบอร์โทร อีเมล ที่อยู่ รูปถ่าย ตำแหน่ง
  • เสียงพูด: โหมดฝึกออกเสียงใช้ระบบรู้จำเสียงของเบราว์เซอร์ (เช่น Chrome อาจส่งเสียงไปประมวลผลที่ผู้ให้บริการเบราว์เซอร์) แอปนี้ไม่บันทึกหรือส่งเสียงไปที่เซิร์ฟเวอร์ของโรงเรียน
วัตถุประสงค์

เพื่อการเรียนรู้คำศัพท์ภาษาอังกฤษ ติดตามระดับ CEFR และความก้าวหน้าของนักเรียนโดยครู เท่านั้น ไม่ใช้เพื่อโฆษณาและไม่ขาย/ส่งต่อให้บุคคลภายนอก

ใครเห็นข้อมูล
  • นักเรียนเห็นข้อมูลของตัวเอง และอันดับในห้อง (ชื่อเล่น XP ระดับ)
  • ครูที่มีรหัสครูเห็นรายงานของนักเรียน
ที่เก็บข้อมูล

ฐานข้อมูล Supabase (ศูนย์ข้อมูลสิงคโปร์) และเว็บโฮสต์ GitHub Pages ซึ่งอาจบันทึก log การเข้าถึง (เช่น IP) ตามนโยบายของผู้ให้บริการ

ระยะเวลาเก็บ

ตลอดปีการศึกษาที่ใช้งาน และลบเมื่อสิ้นสุดโครงการหรือเมื่อนักเรียน/ผู้ปกครองขอ

สิทธิของนักเรียนและผู้ปกครอง

ขอดู แก้ไข หรือลบข้อมูลได้ — ลบเองได้ทันทีที่เมนู “ฉัน → ลบบัญชีและข้อมูลของฉัน” หรือแจ้งครู สำหรับนักเรียนที่ยังไม่บรรลุนิติภาวะ โปรดให้ผู้ปกครองรับทราบก่อนสมัคร (พ.ร.บ.คุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562)
